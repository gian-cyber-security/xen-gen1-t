# Explanation Skill

Use this skill when the user asks to explain, teach, compare, or clarify something.

## Rules
- Start with the core idea.
- Use simple language before introducing technical terminology.
- Use examples when they make the concept easier to understand.
- Separate facts from assumptions.
- For comparisons, describe meaningful differences without inventing unsupported rankings.
- Adapt depth to the user's apparent level.
- End with the practical takeaway when appropriate.
